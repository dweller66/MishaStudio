# MishaClip Studio 0.3.1
Открытый (MIT) видеоредактор в стиле CapCut с локальной Qwen (через Ollama).

## Запуск
- **Есть Python:** двойной клик по `MishaClipStudio.pyw` — откроется окно загрузчика.
- **Нет Python:** загрузи проект на GitHub — Actions сам соберёт `MishaClipStudio.exe` (вкладка Actions → Artifacts).
  Один exe: он скачает встроенный Python, библиотеки, FFmpeg, Ollama и Qwen, а потом откроет редактор.
  При следующих запусках редактор открывается сразу.

## Что умеет
Плеер, таймлайн (разрезать, удалить, двигать, тянуть края), undo/redo, вертикальный 9:16, экспорт MP4 (NVENC/CPU),
автосохранение каждые 15 минут, режим слабого ПК (прокси 480p), Qwen-команды (белый список, без произвольного кода).

## Данные
Всё хранится в `%LOCALAPPDATA%\MishaClipStudio` (логи — в `logs`).
